# fraddy_ai

Fraddy AI — personal AI assistant project.

## Stack

TypeScript

## Getting started

```bash
git clone https://github.com/ANSHSINGH050404/fraddy_ai.git
cd fraddy_ai
bun install
bun run dev   # or: bun run start
```
